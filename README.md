A responsive vanilla HTML/CSS/JavaScript storefront reconstructed from the supplied 20.43-second screen recording.

## Run locally
1. Extract `sorrell-botanical-skincare.zip`.
2. Open `index.html` in Chrome, Firefox, Safari or Edge.

No npm installation, build step or backend is required.

Optional local server:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.

## Recreated from the video
- Sorrell wordmark and rounded floating navigation (Shop, Bestsellers, Gallery, About), search, bag and account icons.
- Botanical hero: “Botanical Skincare for slower rituals”, apothecary/tree visual and plant-derived/refillable/skin-kind badge.
- Product cards with product tags, scent/variant swatches, descriptions, prices and Add to Cart buttons.
- Shopping bag side drawer with line items, quantity increase/decrease, subtotal and demo checkout.

- Ritual category cards: Face Ritual, Body Bloom, Bath House and Home Glow.

- Customer review cards and 4.9/5 review summary.

- Responsive mobile navigation, search filtering and toast feedback.

## Source extraction note
The supplied 20.43-second video shows a rendered Sorrell storefront. It does not show a readable source-code editor or complete original project files. The tiny bottom watermark is not source code. This project is a new runnable reconstruction based on visible page sections, wording and interactions, not a verbatim extraction of the original website's source.

## Demo limitations
- Product names, product prices and marketing copy are recreated from readable video details where possible; additional catalogue entries are illustrative.
- Cart and newsletter interactions run locally in the browser. Checkout does not process payments.
- No inventory, customer accounts, order system, CMS, payment gateway or email service is connected.
- Product photography loads from Unsplash and Google Fonts loads from Google Fonts, so an internet connection is needed for those remote assets. The layout still works with fallback fonts if they are unavailable.
